\# Frase para pedir documentación con formato especial



Para que Copi genere documentación usando el formato con `|||` para los bloques de código internos, usá esta frase:



\*\*“Copi, modo documentación: todo dentro de ``` y los bloques de código internos con |||. Sin usar ``` adentro.”\*\*



También podés usar esta variante más corta:



\*\*“Copi, generá documentación en Markdown encerrada en ``` y usando ||| para los bloques de código internos.”\*\*



Con cualquiera de estas frases, Copi va a:

\- Encerrar todo el documento dentro de ```

\- Evitar usar ``` internos

\- Usar `|||` para los bloques de código

\- Mantener un estilo limpio, técnico y consistente
